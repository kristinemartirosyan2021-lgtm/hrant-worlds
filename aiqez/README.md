# AIQEZ Creative AI Studio — պատվերների կայք (v0.1, փորձնական)

Հեռախոսների համար նախատեսված, ամբողջությամբ հայերեն պատվերների կայք։
Աշխատում է առանց build-ի և առանց սերվերի՝ սովորական HTML/CSS/JS։

> ⚠️ **Փորձնական ռեժիմ։** Պատվերները ոչ մի տեղ չեն ուղարկվում և չեն պահպանվում։
> Կայքը դա հստակ ասում է վերևի ժապավենում, ձևի մեջ և ուղարկելուց հետո։

## Ինչպես բացել նախադիտումը

- **Ամենապարզը՝** բացիր `aiqez/index.html` ֆայլը բրաուզերում (կրկնակի սեղմիր)։
- **Տեղական սերվերով՝** `aiqez` թղթապանակից գործարկիր `python3 -m http.server 8080`
  և բացիր `http://localhost:8080`։ Հեռախոսով փորձելու համար նույն Wi‑Fi‑ում բացիր
  `http://<համակարգչի-IP>:8080`։

## Ֆայլեր

| Ֆայլ | Ինչ է պարունակում |
|---|---|
| `config.js` | **Գներ, ծառայություններ, լեզուներ, փորձնական ռեժիմ** — փոփոխությունների միակ տեղը |
| `index.html` | Էջի կառուցվածքը |
| `styles.css` | Դիզայն (սպիտակ ֆոն, սև տեքստ, մանուշակագույն շեշտեր) |
| `app.js` | Ձևի ստուգում, լուսանկարների նախադիտում, ամփոփում |
| `order-service.js` | Պատվերի ուղարկման շերտ (հիմա՝ միայն փորձնական) |
| `tests/smoke.test.mjs` | Ավտոմատ ստուգում հեռախոսի չափսով բրաուզերում |

### Գների փոփոխություն

`config.js`-ում յուրաքանչյուր ծառայության համար՝

```js
price: null,      // → «Արժեքը՝ ըստ պատվերի»
price: 25000,     // → «25 000 ֏»
priceFrom: true,  // → «սկսած 25 000 ֏»
```

## Ստուգում

```bash
NODE_PATH=$(npm root -g) node aiqez/tests/smoke.test.mjs
```

Ստուգում է՝ գլխավոր էջը, 4 ծառայությունը և գները, ծառայությունից ձևին անցումը,
հայերեն սխալները, հեռախոսի/Telegram-ի և ամսաթվի ստուգումը, լուսանկարների
նախադիտումն ու հեռացումը, ամփոփումը, և որ փորձնական ռեժիմում պատվերը **չի**
ներկայացվում որպես հաջող ուղարկված։

## Հաջորդ քայլերը (իրական աշխատանքի համար)

1. **Պատվերների պահպանում** — սերվեր/ֆունկցիա + տվյալների բազա, լուսանկարների պահոց։
2. **Ծանուցում տիրոջը** — օր.՝ Telegram բոտ կամ email, ամեն նոր պատվերի մասին։
   Բոտի token-ը պահվում է միայն սերվերում։
3. **Անվտանգ վճարում** — վճարային ծառայության (օր.՝ Idram, Ameriabank vPOS, Stripe)
   վճարման էջ, որին սերվերը ուղղորդում է։ Քարտի տվյալները կայքը չի տեսնում։
4. Միացնելուց հետո՝ `config.js`-ում `demoMode: false` և `orderEndpoint: "https://…"`։
   Սերվերը պետք է վերադարձնի `{ orderId, paymentUrl? }` (տես `order-service.js`)։
