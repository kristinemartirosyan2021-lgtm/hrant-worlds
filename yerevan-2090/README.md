# Երևան 2090․ Ժամանակի պահապանը

Վերևից դիտվող 2D գործողությունների խաղ բրաուզերի համար՝ ամբողջությամբ հայերեն։

2090 թվականի Երևանում ժամանակի փորձարկումը ձախողվել է, և քաղաքում բացվել են պորտալներ։ Դու պահապան ես, որը կարող է դանդաղեցնել ժամանակը։ Հավաքիր էներգիայի բյուրեղները, փակիր պորտալները և հաղթիր Քրոնոս-Պահակին։

## Ինչպես գործարկել

Խաղը մեկ ֆայլ է՝ `index.html`։ Այն չունի կախվածություններ և հավաքման կարիք չունի։

- Բացիր `index.html`-ը ցանկացած ժամանակակից բրաուզերում, կամ
- տեղադրիր ցանկացած ստատիկ հոսթինգում (GitHub Pages, Netlify և այլն)։

## Կառավարում

| Գործողություն | Համակարգիչ | Հեռախոս |
|---|---|---|
| Շարժում | WASD / սլաքներ | Ջոյստիկ էկրանի ձախ կեսում |
| Հարձակում | Ավտոմատ | Ավտոմատ |
| Կտրուկ ցատկ (անխոցելի) | Space / Shift | «Ցատկ» կոճակ |
| Ժամանակի դանդաղեցում (3 վրկ, վերականգնում՝ 15 վրկ) | E / Q | «Ժամանակ» կոճակ |
| Դադար | P / Esc | ⏸ կոճակ |
| Ձայն | M | 🔊 կոճակ |

Ստեղները կապված են ֆիզիկական դիրքի հետ, ուստի աշխատում են նաև հայերեն դասավորությամբ։

## Խաղի կառուցվածքը

- **6 ալիք** (մոտ 4–6 րոպե)՝
  1. Առաջին ճեղքը. արագ հետապնդողներ
  2. Կրակի գիծ. հեռվից կրակող աշտարակներ
  3. Պողպատե պատ. զրահակիրներ՝ գետնին հարվածով
  4. Ժամանակի փոթորիկ. ճեղքեր խաղացողի շուրջ, եռակի կրակոց
  5. Երկվորյակ պորտալներ. երկու պորտալ միաժամանակ
  6. Քրոնոս-Պահակ. գլխավոր թշնամի՝ նախապես նշվող հարձակումներով (օղակ, գրոհ, հարված գետնին, պարույր, օգնականներ), երկու փուլով
- **Պորտալի փակում**. հավաքիր անհրաժեշտ բյուրեղները, ապա 5 վայրկյան մնա պորտալի շրջանում։
- **13 ուժեղացում**. ամեն նոր մակարդակում ընտրիր երեքից մեկը (կրկնակի կրակոց, վահան, արագացում, կայծակնային հարված, դրոն և այլն)։
- **Ամեն խաղում նոր քարտեզ**. շենքերը, պորտալները և բյուրեղները պատահական դիրքեր են ստանում։
- **Ուսուցում** առաջին խաղի ընթացքում (կարելի է կրկնել կարգավորումներից)։

## Պահպանում

Լավագույն արդյունքը, վիճակագրությունը, վերջին խաղերը, կարգավորումները և բացված տեսքերը (Պահապան, Ծիրան, Արարատ, Նուռ, Գառնի) պահվում են միայն այս սարքի բրաուզերում (`localStorage`)։
