# 🌍 Hrant Worlds

**Hrant Worlds**-ը հայկական 2D բրաուզերային արկածային խաղ է։ Գլխավոր հերոսը՝ Հրանտը, անցնում է տարբեր աշխարհներով, հաղթահարում փորձությունները և բացահայտում գաղտնի վայրերը։

## 🎮 Հիմնական հնարավորությունները

- 10 աստիճանաբար բարդացող փուլ
- Հայերեն խաղային միջավայր
- Միավորներ, կյանքեր և փուլի ցուցիչ
- Թաքնված բոնուսներ ու գաղտնի սենյակներ
- Խաղի պահպանում և շարունակություն
- Ձայնի կարգավորումներ
- Ամբողջ էկրանով խաղալու հնարավորություն
- Հարմարեցված հեռախոսի և համակարգչի համար

## 🕹️ Կառավարում

- **← / →** կամ **A / D** — շարժվել
- **Space / ↑** — ցատկել
- **Esc** — դադար

## 🚀 Զարգացման փուլ

Խաղը մշակման փուլում է։ Առաջին խաղացվող տարբերակը շուտով կավելացվի այս նախագծում։
