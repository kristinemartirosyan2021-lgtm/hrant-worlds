# 🌍 Hrant Worlds

## ▶️ [ԽԱՂԱԼ ՀԻՄԱ](https://hrant-worlds-game.kristinemartirosyan.chatgpt.site)

**Hrant Worlds**-ը հայկական 2D բրաուզերային արկածային խաղ է։ Գլխավոր հերոսը՝ Հրանտը, անցնում է տարբեր աշխարհներով, հաղթահարում փորձությունները և բացահայտում գաղտնի վայրերը։

> 📱 Հեռախոսով խաղալիս շրջիր այն հորիզոնական դիրքով։ Ոչինչ ներբեռնելու կարիք չկա։

## 🎮 Հիմնական հնարավորությունները

- 10 աստիճանաբար բարդացող աշխարհ
- Հայերեն խաղային միջավայր
- Միավորներ, կյանքեր և փուլի առաջընթաց
- Շարժվող թշնամիներ ու վտանգավոր խոչընդոտներ
- Թաքնված բոնուս և գաղտնի սենյակ յուրաքանչյուր աշխարհում
- Խաղի պահպանում և շարունակություն
- Ձայնի կարգավորում և fullscreen ռեժիմ
- Հեռախոսի էկրանային կոճակներ
- Համակարգչի ստեղնաշարով կառավարում

## 🕹️ Կառավարում

### Հեռախոս

Օգտագործիր էկրանի **←**, **→** և **↑ ՑԱՏԿ** կոճակները։

### Համակարգիչ

- **← / →** կամ **A / D** — շարժվել
- **Space / ↑ / W** — ցատկել
- **P / Esc** — դադար

## 🔐 Խաղային պրոֆիլ

Առաջին բացման ժամանակ խաղը խնդրում է անուն և Gmail։ Այդ տվյալները պահվում են միայն քո սարքի բրաուզերում և ոչ մի տեղ չեն ուղարկվում։

## ✅ Կարգավիճակ

Առաջին խաղացվող տարբերակը պատրաստ է և հրապարակված է։

Հիմնական խաղային կոդը՝ `app/game.tsx`  
Դիզայնը՝ `app/globals.css`
